# 프로젝트 관리 (핸썬)

프로젝트 개요와 하드웨어 발주·납품 내역을 기록하고 보는 웹 도구입니다.

- 화면: 이 저장소 (GitHub Pages)
- 저장: 관리자 구글 계정의 스프레드시트 + Apps Script 웹 앱 (`apps-script/`)
- 공동 비밀번호가 맞아야만 읽고 쓸 수 있습니다. 이 저장소에는 데이터와 비밀번호가 들어 있지 않습니다.

## 고칠 때

- `index.html` 아래쪽의 `Version 01` 을 한 단계 올리고, `sw.js` 의 `VERSION` 도 같이 올립니다.
- Apps Script를 고친 뒤에는 `apps-script` 폴더에서 `clasp push` 후 기존 배포를 새 버전으로 바꿉니다 (`clasp deploy -i <배포 ID>`). 그래야 웹 앱 주소가 그대로 유지됩니다.
- 현 상황 선택지는 `apps-script/Code.js` 맨 위 `STATUSES_DEFAULT` 를 고치거나, Apps Script 프로젝트 설정의 스크립트 속성에 `STATUSES` (쉼표로 구분)를 넣어 바꿉니다.

## 품목 별칭 사전

- 스프레드시트의 `별칭 사전` 시트(견적 모델명 → ERP 품목코드)와 `전체 품목` 시트(이카운트 품목)를 프로젝트 관리와 재고 확인(ilhun425/hanson-stock-check)이 함께 씁니다.
- 엑셀로 품목을 올리면 사전('확실'만) → 기호 무시 비교 → 품명·매입처 비교 순서로 ERP 품목코드를 붙입니다. 사람이 확인한 짝은 사전에 더해집니다.
- 재고 확인은 공동 비밀번호, 또는 스프레드시트 메뉴 [핸썬 관리 > 재고 확인 암호 등록]으로 등록한 재고 앱 암호로 사전만 읽고 더할 수 있습니다.
- 처음 자료와 전체 품목 목록은 회사 자료라 이 저장소에 넣지 않습니다. `dev/make-seed.js`로 `apps-script/Seed.js`(git에서 제외)를 만들어 `clasp push`로만 올리고, 메뉴 [핸썬 관리 > 별칭 사전·전체 품목 가져오기]로 시트에 옮깁니다. 전체 품목을 새 목록으로 바꿀 때도 같은 순서입니다 (별칭 사전은 비어 있을 때만 채우므로 사람이 더한 줄은 지워지지 않습니다).

## 카톡 발주 내역 가져오기

- 목록 화면의 [카톡 확인 대기]에서 카톡 PC '대화 내보내기' txt를 올리면, 화면이 메시지로 나누고 전화번호·계좌번호를 지운 뒤 서버의 `카톡 메시지` 시트에 저장합니다 (날짜+시각+보낸 사람+내용으로 중복을 거릅니다).
- 서버(`apps-script/Kakao.js`)가 규칙으로 발주·재고출고·납품·신규 프로젝트를 찾아 `카톡 확인 대기` 시트에 넣고, 사람이 [맞음]을 누른 것만 발주·납품 시트에 기록합니다 (출처: 카톡 날짜·시각·보낸 사람). 유료 API는 쓰지 않습니다.
- 규칙을 고칠 때는 `dev/`의 시험 도구(git에서 제외)로 실제 대화 파일을 돌려 보고 바꿉니다.
- 카톡 원문과 시험용 파일은 이 저장소에 넣지 않습니다 (`dev/`는 git에서 제외).
